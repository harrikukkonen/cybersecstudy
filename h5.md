### Schneier 2015: Applied Cryptography
- Chapter 1 - Foundations: 1.1 Terminology
- Basic principle of cryptography: Modern Cryptography hides plaintext (M) into ciphertext (C) using a key (K). Some algorithms can also use different encryption key and decryption key. Cryptanalysis tries to break ciphertext without the key.
- Cryptography's other jobs: It also ensures authentication, integrity, and nonrepudiation.
- Symmetric vs. Asymmetric: Symmetric encryption uses the same secret key for both encrypt and decrypt. Public-key (asymmetric) encryption uses a public key to encrypt and separate private key to decrypt.

Source: https://learning.oreilly.com/library/view/applied-cryptography-protocols/9781119096726/08_chap01.html#chap01-sec001
- Chapter 2 - Protocol Building Blocks: 2.5 Communications Using Public-Key Cryptography
- Basic principle of public-key: Works like a mailbox. Anyone can drop a message in with your public key, but only you can unlock it with your private key. No need to share a secret password beforehand to the other party.
- Hybrid cryptosystems: Public-key cryptosystems are too slow for big data and vulnerable to chosen-plaintext attacks. Public-key cryptosystem is used just to safely share a temporary session key and then fast symmetric cryptosystem handles the actual data.

Source: https://learning.oreilly.com/library/view/applied-cryptography-protocols/9781119096726/10_chap02.html#chap02-sec005

### Karvinen 2023: PGP - Send Encrypted and Signed Message - gpg
- PGP basics: Uses gpg on Linux to encrypt messages (outsiders cant read them) and sign them (receiver knows it is actually from trusted source and hasnt been tampered with).
- Key exchange and trust: Both partys generate keypairs and share their public keys. Before trusting a key received over the internet it needs to be verified via another channel (like a phone call or trusted third party) and sign it.
- Encrypting and signing: The sender encrypts the file with the receiver's public key and signs it with their own secret key. Even the sender can't decrypt it anymore after this.
- Decrypting: The receiver runs decrypt on the received message which uses their own secret key to unlock the message and the senders public key to verify the signature.

Source: https://terokarvinen.com/2023/pgp-encrypt-sign-verify/
