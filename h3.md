## x) Article summarys

- Heinonen 2026: How to Install Linux to Virtualbox?
   - Prerequisites and VM sizing: VT-x should enabled/checked in UEFI/BIOS(Improves the performance), VM should be configured with at least 4 GB RAM, 2 CPU core, 20-40GB disk space and UEFI enabled.  
   - ISO image and live testing: Debian 13 (Trixie) is downloaded as hybrid live ISO. This allows user to check full hardware verification before full installation.  
   - Installation and post-setup: The installation is completed via the Calameras graphical installer. Setting up a standard user account and running "sudo apt-get update and sudo apt-get" upgrade immediately after the first reboot to get the latest updates.
   - Own thought: As I did the Debian installation already during previous assignments without any instructions, I did not do any tests via live iso. I just installed the Debian straight when booting from the ISO. Luckily everything worked okay :) I also additionally installed VirtualBox Guest Additions ISO to improve user experience(For example bidirectional clipboard support).
- Karvinen 2020: Command Line Basics Revisited
   - Navigation, files and structure: Basic system navigation happens with pwd, ls, cd, nano(text editor) and rm (no trash). File system does not have drive letters. /home/ for user files, /etc/ system configs and /var/log for system logs. 
   - Effiency and remote management: Using tab completion for commands prevents syntax and path typos, man pages --help gives built-in documentation, command history can be searched via history / ctrl+r and secure remote administration and file transfer are done with ssh and scp. 
   - Privilege model: Administrative requiring tasks need to be called using sudo only when required.
